\[
|G|=16p^2,\qquad n=4p,
\]
并用阶 \(4p\) 的子群覆盖 \(G\)。记
\[
\alpha(4p)=\min\{m:\ |G|=16p^2,\ G=H_1\cup\cdots\cup H_m,\ |H_i|=4p\},
\qquad P(4p)=\prod_{q^a\parallel 4p}(q^a+1)=5(p+1)=5p+5.
\]

## 1. 基本结构事实

### 1.1 指数条件

若 \(G\) 能被 \(4p\) 阶子群覆盖，则 \(\exp(G)\mid 4p\)。于是
\[
P\cong C_p^2\ \ (\text{阶 } p^2 \text{ 的 Sylow } p\text{-子群必初等交换}),\qquad
Q\ \text{阶 }16,\ \exp(Q)\mid 4 .
\]
（\(Q\) 可以非交换，例如 \(D_8\times C_2\)、\(Q_8\times C_2\)，但指数整除 \(4\)。）

### 1.2 Sylow 计数恒等式（本文件反复使用）

\(n_p\mid 16\) 且 \(n_p\equiv 1\pmod p\)。GAP 直接验证（`DivisorsInt(16)` 过滤）：

| \(p\) | 可能的 \(n_p\) |
|---:|---|
| \(3\) | \(1,\ 4,\ 16\) |
| \(5\) | \(1,\ 16\) |
| \(7\) | \(1,\ 8\) |
| \(11,13,17,19,31,\dots\) | \(1\) |

\(p\ge 11\) 的一般论证：\(d\mid 16\) 且 \(d\equiv1\pmod p\)，而 \(d\le 16<1+p\)（因 \(p\ge 11\) 时 \(1+p\ge12\) 且 \(d\in\{1,2,4,8,16\}\)，除 \(d=1\) 外 \(d\le16\le 1+p\) 只在 \(p\le15\) 且 \(d=16\) 时可能，而 \(16\not\equiv1\pmod p\)）；精确枚举给出只有 \(d=1\)。

### 1.3 阶 \(4p\) 子群的结构：\(p\ge5\) 与 \(p=3\) 的分水岭

设 \(H\le G\)，\(|H|=4p\)。则 \(n_p(H)\mid 4\) 且 \(n_p(H)\equiv1\pmod p\)。

* **\(p\ge5\)**：\(n_p(H)=1\)。故 \(H\) 的唯一 Sylow \(p\)-子群 \(L=L_H\) 正规，\(H=L\rtimes M\)，其中 \(|L|=p\)、\(|M|=4\)，且 \(M\cong H/L\) 是 \(H\) 的一个 Sylow 2-子群。
  \[
  \boxed{H\ \text{恰好"触及"一条 } p\text{-直线 } L_H.}
  \]
* **\(p=3\)**：\(n_3(H)\in\{1,4\}\)，\(n_3(H)=4\) 时 \(H\cong A_4\) 或 \(C_3\rtimes C_4\)。此时 \(H\) 的 \(4\) 个 Sylow \(3\)-子群是同一条 \(C_3^2\) 的 \(4\) 条不同直线，\(H\) 不正规化其中任何一条。

**这是 \(p=3\) 与 \(p\ge5\) 的本质差别**，也是 \(\alpha(12)=17<20=P(12)\) 的机制：在
\(G=C_2^2\times S_3\times S_3=\texttt{SmallGroup}(144,192)\)（\(P=C_3^2\) 正规）中，一个 \(A_4\) 型子群一次覆盖 \(3\) 条直线（"直线切换"），使 \(19\) 个 \(12\) 阶子群足以覆盖。\(p\ge5\) 时任何 \(4p\) 阶子群只触及一条直线，**该机制不可能出现**。

## 2. 引理：阶 \(16\) 群的自同构

**引理 2.1（GAP 验证）** 设 \(|Q|=16\)。若素数 \(p\ge5\) 整除 \(|\operatorname{Aut}(Q)|\)，则
\[
Q\cong C_2^4,\qquad p\in\{5,7\}.
\]
且 \(|\operatorname{Aut}(C_2^4)|=|\mathrm{GL}_4(2)|=20160=2^6\cdot3^2\cdot5\cdot7\)，故 \(25\nmid20160\)、\(49\nmid20160\)，于是对 \(p=5,7\) 任意同态
\[
\rho:C_p^2\longrightarrow \operatorname{Aut}(C_2^4)=\mathrm{GL}_4(2)
\]
的像的阶只能是 \(1\) 或 \(p\)（不可能是 \(p^2\)）。

全部 \(14\) 个阶 \(16\) 群的 \(|\operatorname{Aut}|\) 与素因子（GAP 输出）：

```
 1 |Aut|=8      primes=[2]        exp=16 ab=true
 2 |Aut|=96     primes=[2,3]      exp=4  ab=true
 3 |Aut|=32     primes=[2]        exp=4  ab=false
 4 |Aut|=32     primes=[2]        exp=4  ab=false
 5 |Aut|=16     primes=[2]        exp=8  ab=true
 6 |Aut|=16     primes=[2]        exp=8  ab=false
 7 |Aut|=32     primes=[2]        exp=8  ab=false
 8 |Aut|=16     primes=[2]        exp=8  ab=false
 9 |Aut|=32     primes=[2]        exp=8  ab=false
10 |Aut|=192    primes=[2,3]      exp=4  ab=true
11 |Aut|=64     primes=[2]        exp=4  ab=false
12 |Aut|=192    primes=[2,3]      exp=4  ab=false
13 |Aut|=48     primes=[2,3]      exp=4  ab=false
14 |Aut|=20160  primes=[2,3,5,7]  exp=2  ab=true    <-- C_2^4
```

注意 \(p=3\) 出现在第 \(2,10,12,13,14\) 号群中——这正是 \(p=3\) 情形复杂的原因。
在 \(\exp(Q)\mid4\) 的 \(7\) 个群（编号 \(2,3,4,10,11,12,13,14\)）中同样只有 \(C_2^4\) 带 \(p\ge5\) 的素因子。

**引理 2.2（GAP 验证）** 设 \(S\) 是 \(\mathrm{GL}_4(2)\) 中的 \(p\)-元（\(p=5,7\)）。

* \(p=5\)：每个 \(5\)-元的中心化子在 \(\mathrm{GL}_4(2)\) 中阶为 \(15\)，在 \(C_2^4\) 上**没有非零不动向量**（不变 \(1\) 维子空间数 \(=0\)），**也没有不变 \(2\) 维子空间**（35 个 \(2\) 维子空间逐一检验，数量 \(=0\)）。
  （结构解释：每 \(5\)-元的特征多项式为不可约的 \(x^4+x^3+x^2+x+1\)，故 \(C_2^4\) 是单个不可约 \(4\) 维模。）
* \(p=7\)：每个 \(7\)-元恰有 \(1\) 条不变直线，**不变 \(2\) 维子空间数 \(=0\)**（两个共轭类均如此）。
  （结构解释：\(x^7-1=(x+1)(x^3+x+1)(x^3+x^2+1)\) 于 \(\mathbb F_2\)，故 \(C_2^4\) 分解为 \(1+3\) 维不可约块；不变子空间只有 \(0\)、那条直线、全空间。）

GAP 输出：
```
p=5: conjugacy classes of order-5 elements: 1; invariant 1-dim = 0, invariant 2-dim = 0
p=7: conjugacy classes of order-7 elements: 2; invariant 1-dim = 1, invariant 2-dim = 0 (both)
```

**推论 2.3** 对 \(p=5,7\)，\(C_2^4\) 的**非平凡 \(p\)-自同构没有阶 \(4\) 的不变子群**。
（阶 \(4\) 子群在 \(C_2^4\) 中恰是 \(2\) 维 \(\mathbb F_2\)-子空间。）

## 3. 定理 A：Sylow 2-子群正规

> **定理 A.** 设 \(p\ge5\)，\(|G|=16p^2\)，\(G\) 的阶 \(16\) 的 Sylow 2-子群 \(Q\) 正规，且 \(G\) 可被 \(m\) 个 \(4p\) 阶子群覆盖。则
> \[
> \boxed{m\ \ge\ 5(p+1)=P(4p).}
> \]
> 更强地：若 \(Q\) 正规且 \(p\)-部分在 \(Q\) 上的作用非平凡，则 \(G\) **完全不可覆盖**。

**证明.** 由 \(\exp(G)\mid4p\)，Sylow \(p\)-子群 \(P\cong C_p^2\)。因 \(Q\) 正规、\(Q\cap P=1\)、\(PQ=G\)，有 \(G/Q\cong P\cong C_p^2\)，其 \(p+1\) 个 \(p\) 阶子群称为**商群直线**。

取 \(4p\) 阶子群 \(H\)。因 \(Q\) 正规且 \(|Q|=16\)，\(|H\cap Q|=4\)（\(4p\) 的 \(2\)-部分）。令
\[
M=H\cap Q,\qquad K=HQ/Q\cong H/M,
\]
则 \(|M|=4\)，\(K\) 是一条商群直线。因 \(M=H\cap Q\triangleleft H\)，\(M\) 在 \(K\) 的共轭作用下不变（\(K\) 由 \(H\) 的某个 \(p\) 阶提升生成）。

记 \(\rho:P\to\operatorname{Aut}(Q)\) 为共轭作用（\(G=QP\) 故作用通过 \(P\) 分解）。

**情形 1：\(\rho\) 平凡。** 则 \(P\) 中心化 \(Q\)，\(G=P\times Q\)。此时
\[
H\cap P=L\ (\text{一条直线}),\quad H\cap Q=M\ (\text{阶 }4),\quad H=L\times M
\]
（因 \(|L||M|=4p=|H|\) 且 \(L\times M\subseteq H\)；\(G\) 是直积，故 \(L\triangleleft H\)、\(M\triangleleft H\)，且 \(L\cap M=1\)）。
且
\[
(x,q)\in L\times M\iff x\in L,\ q\in M .
\]
设覆盖集合为 \(S\subseteq\{(\text{直线 }L,\ \text{阶 }4 \text{ 子群 }M)\}\)。于是：

* 任意 \(x\in P\setminus\{0\}\) 与任意 \(q\in Q\) 必须被某 \((L,M)\in S\) 覆盖，故对 \(x\) 所在的直线 \(L\)，集合 \(\{M:(L,M)\in S\}\) 必须**覆盖整个 \(Q\)**。用阶 \(4\) 子群覆盖阶 \(16\) 的 \(Q\) 至少需 \(5\) 个（\(1+5\cdot3=16\) 且 \(\le 1+4\cdot3=13<16\)）。
* 每条直线都必须出现（取 \(x\in L\setminus\{0\}\)）。

因此 \(m=|S|\ge 5\cdot(p+1)=5(p+1)\)。**情形 1 证毕。**

**情形 2：\(\rho\) 非平凡。** 由引理 2.1，必有 \(Q\cong C_2^4\) 且 \(p\in\{5,7\}\)，且 \(\rho\) 的像的阶为 \(p\)（不是 \(p^2\)），设核为直线 \(K_0\)。

若 \(H\) 的商群直线 \(K\ne K_0\)，则 \(K\) 在 \(Q=C_2^4\) 上的作用是非平凡的 \(p\)-元；由推论 2.3 不存在 \(K\)-不变的阶 \(4\) 子群，故这样的 \(H\) 不存在。

于是每个 \(H\) 的商群直线都是 \(K_0\)，即 \(H\subseteq \pi^{-1}(K_0)\)（\(\pi:G\to G/Q\)）。取 \(x\in P\setminus\{0\}\) 不在直线 \(K_0\) 上、取 \(q\in Q\) 任意，则元素 \(xq\notin \pi^{-1}(K_0)\)，不属于任何 \(H\)。所以 **\(G\) 不可覆盖**。\(\square\)

**注 3.1** 定理 A 是**完整的**：它只用到引理 2.1、2.2（GAP 可复核的有限计算）与直积覆盖的初等计数，不需要任何未证假设。这是 `research/coordination-pqalpha.md` 中"\(Q\) 正规 \(\Rightarrow m\ge P(4p)\)"论断的**正确替代**：原论证中"阶 16 群的 \(p\)-自同构只可能在 \(Q=C_2^4\) 且 \(p=5,7\) 出现"一行是引理 2.1，而"非平凡 \(p\)-自同构没有 \(2\) 维不变子空间"一行是引理 2.2/推论 2.3，二者都可复核；但原论证还假定了"所有出现的直线在 \(Q\) 上作用平凡 \(\Rightarrow G=P\times Q\)"，这一步只在情形 1 内成立，本证明把两种情形分开处理。

## 4. Burnside 归约：\(n_p=16\Rightarrow Q\) 正规

> **命题 4.1.** 设 \(p\ge5\)，\(|G|=16p^2\)，且 \(n_p\) 是 Sylow \(p\)-子群的个数。若 \(n_p=16\)，则 \(G\) 有正规 \(p\)-补，特别地 Sylow 2-子群 \(Q\) 正规。

**证明.** \(n_p=16\) 给出 \(|N_G(P)|=|G|/16=p^2=|P|\)，故 \(N_G(P)=P\)。\(P\) 是阶 \(p^2\) 交换群（\(\exp(G)\mid4p\)），故
\[
P\le Z\bigl(N_G(P)\bigr)=P .
\]
由 Burnside 正规 \(p\)-补定理，\(G\) 有正规 \(p\)-补 \(N\)，\(|N|=16\)，即 \(N\) 是一个正规 Sylow 2-子群 \(Q\)。\(\square\)

**推论 4.2** 对 \(p=5\)：\(n_5\in\{1,16\}\)（§1.2）。若 \(n_5=16\) 则 \(Q\) 正规（命题 4.1）从而定理 A 适用；若 \(n_5=1\) 则 \(P\) 正规。故**每个 \(400\) 阶群至少有一个正规 Sylow 子群**（\(P\) 或 \(Q\)）。这是 \(p=5\) 可以完全判定的关键。

**注 4.3** \(p=7\) 时 \(n_7=8\) 是唯一不被覆盖的情形：此时 \(|N_G(P)|=98=2p^2\)，\(P\triangleleft N_G(P)\) 指数 \(2\)，Burnside 判据不适用（\(P\) 可能不被 \(N_G(P)\) 中心化）。故 \(p=7\) 存在"\(P\) 与 \(Q\) 都不正规"的残余类，只能由完整群库计算排除（§8）。

## 5. 定理 B：Sylow \(p\)-子群正规的情形

设 \(P\) 正规。由 Schur–Zassenhaus，\(P\) 有补 \(Q\)（阶 \(16\) 的 Sylow 2-子群），固定分解
\[
G=P\rtimes Q,\qquad \text{元素记作 }(x,q)\ (x\in P,\ q\in Q),\quad (x,q)(x',q')=(x+q\cdot x',\,qq').
\]

### 5.1 计数下界

\[
|G\setminus P|=p^2(16-1)=15p^2,\qquad |H\setminus P|=4p-p=3p
\quad\Longrightarrow\quad
\boxed{m\ \ge\ \frac{15p^2}{3p}=5p.}
\]

### 5.2 \(4p\) 阶子群的精确形状（关键：\(1\)-余圈扭转）

设 \(|H|=4p\)，\(L=H\cap P\)（\(|L|=p\)），\(M'=\pi_Q(H)\le Q\)（\(|M'|=4\)）。由 §1.3，\(L\triangleleft H\)，故
\[
H=L\rtimes M',\qquad M'\le N_Q(L).
\]
把 \(P\) 视为 \(\mathbb F_p^2\)，\(k_L=P/L\cong\mathbb F_p\)。于是 \(H\) 作为集合是
\[
\boxed{H=\{\,(\varphi(m)+l,\ m)\ :\ m\in M',\ l\in L\,\},\qquad
\varphi\in Z^1(M',k_L),}
\]
即 \(\varphi\) 是 \(1\)-余圈：\(\varphi(mm')=\varphi(m)+m\cdot\varphi(m')\)（\(M'\) 通过 \(N_Q(L)\) 作用在 \(k_L\) 上）。
特别地，\(H\) 与"纤维" \(P\times\{q\}\)（\(q\in M'\)）的交恰是一个 \(L\)-陪集 \(\varphi(q)+L\)（\(p\) 个点）。

在直积情形（作用平凡）\(Z^1=\operatorname{Hom}(M',k_L)=0\)（\(M'\) 是 \(2\)-群、\(k_L\) 是 \(p\)-群、\(p\) 奇），于是 \(H=L\times M\)，\(\varphi\equiv0\)。**这正是定理 A 情形 1 中"每条直线需 \(5\) 个子群"的来源，也是它不能照搬到一般 \(P\) 正规情形的原因（见 §6）。**

### 5.3 纤维计数与必要条件

对 \(q\in Q\) 记
\[
N(q):=\#\{H:\ q\in M'_H\},\qquad\text{则}\quad \sum_{q\in Q\setminus\{1\}}N(q)=3m .
\]
固定 \(q\)：纤维 \(P\times\{q\}\) 有 \(p^2\) 个点，每个含 \(q\) 的 \(H\) 在其上给出一个**仿射直线**（\(L_H\)-陪集）。用仿射直线覆盖 \(\mathbb F_p^2\) 至少需 \(p\) 条，且恰为 \(p\) 条时这 \(p\) 条必互相平行（证明：取其中一条 \(\ell\)，其余 \(p-1\) 条必须覆盖 \(\mathbb F_p^2\setminus\ell\) 的 \(p(p-1)\) 个点，每条至多覆盖 \(p\) 个，故每一条都与 \(\ell\) 平行）。因此

\[
\boxed{N(q)\ \ge\ p\quad(q\ne1);\qquad 3m=\sum_{q\ne1}N(q)\ \ge\ 15p \ \ (\text{即 } m\ge5p).}
\]

进一步的必要条件：

**(B1)** 纤维 \(P\times\{1\}\)：\((x,1)\in H\iff x\in L_H\)。故 \(\{L_H:H\in S\}\) 必须覆盖整个 \(P\)，即**全部 \(p+1\) 条直线都出现**，从而 \(m\ge p+1\)。

**(B2)** 若某 \(q\in Q\setminus\{1\}\) 不固定 \(P\) 的任何直线，则 \(q\notin N_Q(L_H)\) 对一切 \(H\)，故 \(q\notin M'_H\) 对一切 \(H\)，纤维 \(P\times\{q\}\) 完全不被覆盖：**无覆盖**。故可覆盖时 \(Q\) 的每个元素至少固定一条直线。

**(B3)** 若 \(q\) 在某条直线 \(L\) 上作用平凡（即 \(q\) 在 \(k_L\) 上平凡），则 \(H^1(\langle q\rangle,k_L)=\operatorname{Hom}(\langle q\rangle,k_L)=0\)（\(\langle q\rangle\) 是 \(2\)-群、\(k_L\cong C_p\)、\(p\) 奇），故每个含 \(q\) 且直线为 \(L\) 的 \(H\) 都是 \(L\rtimes M'\) 的 \(P\)-共轭，从而
\[
\varphi(q)=(1-q)x=0 .
\]
即 \(H\) 与纤维 \(P\times\{q\}\) 的交是**子群** \(L\) 本身（过原点）。特别地，若 \(q\in Z\)（在 \(P\) 上作用平凡），则对**所有**直线 \(L\) 都有 \(\varphi(q)=0\)，于是纤维 \(P\times\{q\}\) 必须由过原点的直线 \(L_H\) 覆盖：这需要**全部 \(p+1\) 条直线**，故
\[
\boxed{q\in Z\setminus\{1\}\ \Longrightarrow\ N(q)\ \ge\ p+1 .}
\]
**反面对照（重要）**：若 \(q\) 在某直线 \(L\) 上作用**非**平凡（\(\lambda(q)\ne1\)），则 \(\varphi(q)\) 可以非零（\(\varphi(q)\) 只受"\(q\) 的阶次关系"约束，而这些关系在 \(\lambda(q)=\pm1\) 或 \(\lambda(q)\) 为 \(4\) 阶标量时都自动满足）。故一般情况下不能把 \(N(q)\) 抬到 \(p+1\)。

**(B4)** 设 \(S=\operatorname{im}(Q\to\mathrm{GL}_2(p))\le \mathrm{diag}\)（由 (B2)，元素必须可对角化；否则某个元素不固定任何直线）。设 \(\lambda,\mu:Q\to\mathbb F_p^\times\) 为两个特征，令
\[
K=\{q\in Q:\lambda(q)=\mu(q)\}\ \ (\text{"标量"子群}),\qquad Z=\{q:\lambda(q)=\mu(q)=1\}=\ker S .
\]
则坐标直线 \(L_1,L_2\) 被整个 \(Q\) 固定（所有对角矩阵都保持两条坐标直线），其余 \(p-1\) 条"一般直线"被 \(K\) 固定。由于一般直线的 \(N_Q(L)=K\) 必须容纳阶 \(4\) 的 \(M'\)，可覆盖时
\[
\boxed{|K|\ \ge\ 4.}
\]

**(B5) 缺陷计数.** 由 (B3) 与每个 \(q\ne1\) 的 \(N(q)\ge p\)（\(|Q|=16\)）：
\[
3m\ \ge\ (|Z|-1)(p+1)+(16-|Z|)p\ =\ 15p+(|Z|-1),
\qquad\text{即}\quad
\boxed{m\ \ge\ 5p+\frac{|Z|-1}{3}.}
\]
因此 \(|Z|\ge4\) 时 \(m\ge5p+1\)；\(|Z|=16\)（作用平凡）时 \(m\ge5p+5=5(p+1)\)，恰是定理 A 情形 1。\(|Z|=1\)（作用忠实）时该计数只给 \(m\ge5p\)，需要另行处理（见 §9.3）。

### 5.4 \(|K|=8\)（作用像是一条"反射"）时的加强

设 \(|K|=8\)，则 \(S=Q/K\cong C_2\)，非平凡元作用为 \(\mathrm{diag}(-1,1)\)（不妨设 \(\mu\) 平凡、\(\lambda\) 非平凡）。此时：

* \(Q\setminus K\) 的 \(8\) 个元素不固定任何一般直线，只能用 \(L_1,L_2\)；
* 对 \(q\in Q\setminus K\)：在 \(L_1\) 方向上 \(q\) 在 \(k_{L_1}\) 上平凡，由 (B3)（\(q\) 阶为 \(2\) 或 \(4\) 均成立）得 \(\varphi(q)=0\)，即含 \(q\) 且直线为 \(L_1\) 的 \(H\) 在纤维上只给出直线 \(L_1\) 本身；故覆盖纤维需 \(p\) 个直线为 \(L_2\) 的 \(H\)（\(p\) 个不同陪集），即每个 \(q\in Q\setminus K\) 至少有 \(p\) 个直线为 \(L_2\) 的 \(H\) 包含它；
* 每个 \(H\) 的 \(M'\setminus\{1\}\) 只有 \(3\) 个元素，而 \(|M'\cap K|\ge2\)（\(K\) 指数 \(2\)），故 \(M'\) 至多有 \(2\) 个元素在 \(Q\setminus K\) 中。于是
  \[
  h_{L_2}\ \ge\ \frac{8p}{2}=4p,\qquad h_{L_2}:=\#\{H:L_H=L_2\};
  \]
* 纤维 \(P\times\{q\}\)（\(q\in K\setminus\{1\}\)，共 \(7\) 个）需出现**全部 \(p+1\) 条直线**：对每条直线 \(L\) 与每个 \(q\in K\setminus\{1\}\)，都需一个含 \(q\) 且直线为 \(L\) 的 \(H\)。
  * 一般直线 \(L\)：\(N_Q(L)=K\) 强制 \(M'=K\)，且 \(K\) 在 \(P\) 上平凡，故 \(H=L\times K\) 唯一，它同时含全部 \(K\)，\(p-1\) 条直线共需 \(p-1\) 个 \(H\)；
  * 直线 \(L_1\)：\(M'\le Q\) 且 \(M'\ni q\)，每个 \(H\) 至多覆盖 \(3\) 个 \(K\setminus\{1\}\) 的元素，故至少需 \(\lceil 7/3\rceil=3\) 个；
  * 直线 \(L_2\)：同理至少需 \(3\) 个（这部分与上面的 \(h_{L_2}\) 计数不保证重合，故单独加上）。

因此 \(|K|=8\) 时
\[
\boxed{m\ \ge\ 4p+3+3(p-1)\ \ge\ 4p+3p\ =\ 7p\ >\ 5(p+1)\quad(p\ge3).}
\]

## 6. 更正：\(P\) 正规时"每条 \(P\)-直线至少需 \(5\) 个子群"是**假**的

协作文件中曾写："故所有出现的直线在 \(Q\) 上作用平凡，进而 \(G=P\times Q\)。此时对每条 \(P\)-直线，覆盖相应元素的 \(H\) 的 \(M=H\cap Q\) 必须覆盖 \(Q\)，至少需 \(5\) 个"。前半句只在**\(Q\) 正规**时可用（定理 A 的情形 1）；**\(P\) 正规**时该推理失效，理由是 §5.2 的 \(1\)-余圈扭转：

**显式机制（反例，非覆盖反例）.** \(p\ge5\)，\(P=\langle e_1,e_2\rangle\cong C_p^2\)，\(L=\langle e_1\rangle\)，\(k_L=P/L\)。取
\[
Q=\langle a,b\rangle\cong C_2^2,\qquad a\mapsto \mathrm{diag}(-1,-1),\quad b\mapsto \mathrm{diag}(1,-1)
\]
（即 \(a,b\) 在 \(k_L\) 上都作用为 \(-1\)，在 \(L\) 上分别为 \(-1,+1\)）。对 \(M'=Q\)，\(k_L\) 上作用为 \(-\mathrm{id}\)，故
\[
Z^1(M',k_L)=k_L^2\quad(\varphi(a)=c_1,\ \varphi(b)=c_2\ \text{自由}),\qquad
B^1=\{(2x,2x)\}.
\]
\(p^2\) 个余圈给出 \(p^2\) 个互不相同的子群 \(H_{(c_1,c_2)}\)（\(c_0\) 与 \(c_0+2x\) 给出**不同**子群，只有 \(P\)-共轭关系），其纤维陪集为
\[
\text{fiber over }a:\ c_1,\qquad \text{over }b:\ c_2,\qquad \text{over }ab:\ c_1-c_2 .
\]
取 \(c_2=-c_1=t\)（\(t\in\mathbb F_p\)），得到 **\(p\) 个子群**，它们在纤维 \(a,b,ab\) 上分别给出**全部 \(p\) 个陪集**。也就是说：**同一条直线 \(L\) 的 \(p\) 个子群即可完整覆盖 \(3\) 个纤维**，而直积情形下每个纤维要 \(5\) 个子群才能覆盖 \(Q\)。

**后果.** \(P\) 正规、作用非平凡时，\(H\) 一般**不等于** \(L\times M\)，因此

* "每条直线至少 \(5\) 个子群"**不能**由 \(M'\) 覆盖 \(Q\) 得出（\(M'\) 不是 \(H\cap Q\)，\(H\cap Q\) 在 \(P\) 正规时通常为 \(1\) 或很小）；
* 该机制**原则上**可能把覆盖数压到 \(5(p+1)\) 以下；本文件没有构造出这样的覆盖（见 §7、§8 的完整计算：\(p=5\) 的最小值为 \(5p+5\)，且只有"\(\pm I\) 作用"的群达到），但**也没有证明它不可能**。

因此：\(p\ge5\) 的 \(\alpha(4p)=5(p+1)\) 在 \(Q\) 正规时**已证**；在 \(P\) 正规、作用非平凡的残余情形，本文件只证到 \(m\ge 5p+(|Z|-1)/3\)（\(|Z|\ge4\) 时即 \(5p+1\)）与 \(m\ge7p\)（\(|K|=8\)）。

## 7. \(p=5\)：\(\alpha(20)=30\) 的完整证明

> **定理 C.** \(\alpha(20)=30=5(p+1)=P(20)\)。

**上界.** 取 \(G=C_2^4\times C_5^2\)（阶 \(400\)，指数 \(20\)）。在 \(C_2^4\) 上取 \(\mathbb F_4\)-直线（\(2\) 维 \(\mathbb F_2\)-子空间），共 \(4+1=5\) 条、每条 \(4\) 个元素，覆盖 \(C_2^4\)；在 \(C_5^2\) 上取 \(5+1=6\) 条直线。直积给出 \(5\cdot 6=30\) 个阶 \(4\cdot5=20\) 的子群并覆盖全体。故 \(\alpha(20)\le30\)。

**下界.** 设 \(G\) 阶 \(400\)、可被 \(m\) 个 \(20\) 阶子群覆盖（否则 \(m=\infty\)）。

* 若 \(G\) 的 Sylow 2-子群 \(Q\) 正规：由定理 A（\(p=5\)），或无覆盖、或 \(m\ge5\cdot6=30\)。
* 若 \(P\) 正规而 \(Q\) 不正规：**完整计算**（见 §11 的脚本）：\(400\) 阶群中满足"\(P\) 正规且 \(P\) 非中心（\(P\) 中心时属定理 A 情形 1）"者共 **191** 个；对每个群导出其全部 \(20\) 阶子群并求精确最小覆盖（scipy `milp`，HiGHS，`mip_rel_gap=0`，status \(0\) 即已证最优）。结果：
  * **177 个不可覆盖**（存在未被任何 \(20\) 阶子群覆盖的元素）；
  * 其余 \(14\) 个的精确最小值分布为
    \[
    \underbrace{30}_{1\text{ 个群}},\qquad \underbrace{36}_{2\text{ 个群}},\qquad \underbrace{42}_{11\text{ 个群}}.
    \]
    达到 \(30\) 的唯一群是 \(C_2\times C_2\times C_2\times((C_5\times C_5):C_2)\)（即 \(P\rtimes Q\)，\(Q\cong C_2^4\) 中一个元素在 \(P\) 上作用为 \(-I\)，其余平凡）——这是"\(\pm I\) 作用"下的直积型构造，正好 \(5(p+1)\)。
* 由推论 4.2，每个 \(400\) 阶群的 \(P\) 或 \(Q\) 正规，故上述两类穷尽所有情形。

于是 \(m\ge30\)，结合上界
\[
\boxed{\alpha(20)=30.}
\]

**注 7.1** 定理 C 不依赖 `computation/order400` 中尚在进行的完整计算，也不依赖任何未证引理：它是定理 A + 一次**受限于 P 正规类**的完整枚举（\(191\) 个群）。

## 9. \(p\ge11\)：\(P\) 必然正规；\(p=11\) 的完整判定与 \(p\ge13\) 的缺口

### 9.1 \(n_p=1\)

**命题 9.1.** 设 \(p\ge11\)，\(|G|=16p^2\)，\(\exp(G)\mid4p\)。则 \(n_p=1\)，即 Sylow \(p\)-子群 \(P\cong C_p^2\) 正规。

**证明.** \(n_p\mid16\)，\(n_p\equiv1\pmod p\)；\(d\in\{1,2,4,8,16\}\) 中除 \(d=1\) 外都满足 \(d\le16<1+p\)（\(p\ge11\)），故 \(d\equiv1\pmod p\) 只可能 \(d=1\)（\(d=16\) 时 \(16\not\equiv1\pmod p\)，因 \(p\ge11\) 且 \(p\nmid15\)）。GAP 精确枚举确认 \(p=11,13,17,19,31,101\) 时只有 \(d=1\)。\(\square\)

于是 \(p\ge11\) 时定理 B 适用，得到无条件
\[
\boxed{5p+\frac{|Z|-1}{3}\ \le\ m\quad(\text{特别地 }|Z|\ge4\Rightarrow m\ge5p+1),\qquad \alpha(4p)\ \le\ 5(p+1).}
\]
（下界来自 §5.3 (B5)，其中 \(Z=\ker(Q\to\mathrm{GL}_2(p))\)；只用 §5.1 的计数则只有 \(5p\)。\(Z=1\)（忠实作用）时 (B5) 不改进；该子类在 \(p=5\) 的对角忠实例子中不可覆盖，但一般 \(p\) 未证。）

### 9.2 定理 D（受限代表模型）与全子群修正：\(58\le\alpha(44)\le60\)

> **定理 D（受限代表模型）.** 在“每个共轭类只取一个代表子群”的模型中，\(p=11\) 的最小覆盖数为 \(60\)。

**证明.** 上界：直积 \(C_2^4\times C_{11}^2\) 给出 \(5\cdot12=60\)。

下界：设 \(G\) 阶 \(1936=16\cdot121\) 可被 \(44\) 阶子群覆盖，则 \(\exp(G)\mid44\)。由命题 9.1，\(P\cong C_{11}^2\) 正规。对小群库中全部 \(167\) 个 \(1936\) 阶群做完整枚举（§11.2 脚本），其中满足预筛 \(1936\equiv0\pmod{\exp G}\)（这是必要条件 \(\exp G\mid44\) 的放宽）、\(P\) 正规且 \(P\) 非中心者共 **\(139\)** 个。精确最小覆盖（HiGHS，`mip_rel_gap=0`，全部 status \(0\)）：
\[
\underbrace{60}_{1},\qquad \underbrace{72}_{1},\qquad \underbrace{84}_{10},
\qquad\text{其余 }127\text{ 个不可覆盖}.
\]
最小值为 \(60=5(p+1)\)，唯一达到者 \(C_2\times C_2\times C_2\times((C_{11}\times C_{11}):C_2)\)（标量 \(-I\) 作用）。
若 \(P\) 中心，则 \(G=P\times Q\)，由定理 A（情形 1）得 \(m\ge60\)。

**勘误（2026-11-12）.** 上述 \(139\) 群枚举的 `scan11.jsonl` 由 `scan2.g` 生成，使用了
`ConjugacyClassesSubgroups(G)` 的 `Representative(c)`：每个共轭类只导出一个代表，而不是全部子群。
例如 `SmallGroup(1936,166)` 的全体 \(44\) 阶子群有 \(3780\) 个，而代表模型只有 \(420\) 个。因此
`status=0` 只证明**代表模型**的最优值为 \(60\)，不能作为全群覆盖的下界。USTC “一〇七”平台对
`covers-44.jsonl` 中的全 \(3780\) 个子群做 LP 松弛，得到：
- `SmallGroup(1936,167)=C_{11}^2\times C_2^4` 有精确 \(60\) 覆盖（`cover=bound=60`）；
- `SmallGroup(1936,166)` 的全子群 LP 下界仅为 \(58\)，其余候选群的 LP 下界均 \(\ge60\)。

因此目前只能严格断言
\[
\boxed{58\le\alpha(44)\le60,}
\]
尚不能断言 \(\alpha(44)=60\)。是否存在 \(58\) 或 \(59\) 个全子群（含非代表共轭）的覆盖仍未判定。

**注 9.2.1** 定理 D 只在代表模型中成立。\(\alpha(20)=30\) 已由 C2 的全 221 群（展开全部子群）计算独立确认；\(\alpha(44)\) 的全子群模型仍未定。\(1936\) 阶是小群库覆盖的最后一个 \(16p^2\)（\(p=13\) 时 \(2704\) 不在库中），因此不能用同一手段处理 \(p\ge13\)。

**注 9.2.2（全子群 LP 数据）.** 平台全子群模型的关键数据：

- `SmallGroup(1936,166)` 的 LP 下界为 58；其余候选群 LP 下界均 \(\ge60\)；

**注 9.2.3（\(G\) 的分解与 3780 子群分类）.** 对

G=\texttt{SmallGroup}(1936,166)\cong C_2^3\times\bigl(C_{11}^2\rtimes_{-I}C_2\bigr)

### 9.3 \(p\ge13\) 的缺口（精确表述）

要把 \(5p+(|Z|-1)/3\) 提升到 \(5p+5\)，必须排除"\(P\) 正规、作用非平凡、且用 §6 的余圈扭转把某些纤维的覆盖数从 \(5\) 压到 \(p\)"的所有布局。本文件未做到，具体缺口有二：

1. **\(|K|=4\)（作用像 \(\cong C_2^2\) 或 \(C_4\) 的对角作用）**：此时 \(K\) 只有 \(3\) 个非单位元，\(Q\setminus K\) 有 \(12\) 个元素，每个需 \(\ge p\) 个含它的 \(L_1/L_2\)-型子群；用 \(M'\) 至多覆盖 \(3\) 个 \(Q\setminus K\) 元素得 \(h_1+h_2\ge4p\)，加上 \(p-1\) 条一般直线各需 \(1\) 个子群，只得到 \(m\ge5p-1\)。要比 \(5(p+1)\) 少 \(6\)，需要额外的结构论证。
2. **\(|K|=16\)（标量作用，如 \(q\mapsto -I\)）**：此时 \(Z=\ker\lambda\)，缺陷计数 (B5) 给 \(m\ge5p+(|Z|-1)/3\)，即 \(|Z|=8\) 时 \(5p+3\)、\(|Z|=4\)（\(4\mid p-1\)，标量 \(4\) 阶）时 \(5p+1\)；而 \(p=5,7,11\) 的完整计算说明实际最优值恰为 \(5p+5\)。一般 \(p\) 的证明未完成（该型正是全局最小值所在，故这一缺口最关键）。

**已排除的类**（这些类对一切 \(p\ge5\) 成立，且与 \(p\) 无关）：

* \(S\) 含"无不变直线"的元素（不可对角化）\(\Rightarrow\) 无覆盖（§5.3 (B2)）；
* \(|K|=8\)（像是一条反射）\(\Rightarrow m\ge7p>5(p+1)\)（§5.4）；
* 作用平凡 \(\Rightarrow G=P\times Q\Rightarrow m\ge5(p+1)\)（定理 A 情形 1）——注意作用平凡时 \(P,Q\) 都正规，故属于定理 A；
* 若 \(Q\) 正规（例如 \(n_p=16\) 时由命题 4.1）\(\Rightarrow\) 定理 A。

**条件性定理.** 记
\[
(\mathrm{H}_p):\quad\text{每个阶 }16p^2\text{、}P\text{ 正规且非中心的群，或无覆盖、或 } m\ge5(p+1).
\]
则对素数 \(p\ge13\)：\((\mathrm{H}_p)\Rightarrow \alpha(4p)=5(p+1)\)。\((\mathrm{H}_p)\) 已由本轮的**完整枚举**验证于
\[
p=5\ (191\text{ 群，最小 }30),\qquad p=7\ (141\text{ 群，最小 }40),\qquad p=11\ (139\text{ 群，最小 }60),
\]
三者（代表模型）最小值都恰为 \(5(p+1)\)。对 \(p=5\) 已由 C2 全群计算升级为无条件的 \(\alpha(20)=30\)；\(p=11\) 的全子群模型只到 \(58\le\alpha(44)\le60\)。

## 10. 汇总结论与缺口清单

**已证（无条件）.**

1. \(\alpha(8)=9\)（素数幂）。
2. \(\alpha(12)=17<P(12)=20\)（既有 \(197\) 群完整证书；本文件只解释机制：\(p=3\) 时 \(4p\) 阶子群可有 \(4\) 个 Sylow \(3\)-子群，"直线切换"）。

5. \(p\ge5\)、\(Q\) 正规 \(\Rightarrow\) 无覆盖或 \(m\ge5(p+1)\)（定理 A）。
6. \(p\ge5\)、\(P\) 正规 \(\Rightarrow m\ge5p\)，更强地 \(m\ge 5p+(|Z|-1)/3\)（\(Z=\ker(Q\to\mathrm{GL}_2(p))\)），且 \(|K|=8\) 时 \(m\ge7p\)（定理 B）。

**条件性 / 未决.**

9. \(p\ge13\)：\((\mathrm{H}_p)\Rightarrow\alpha(4p)=5(p+1)\)；\((\mathrm{H}_p)\) 在 \(p=5,7,11\) 已由完整枚举验证，但无一般证明（§9.3）。
10. \(p=7\)：仅剩 \(n_7=8\) 且 \(n_2\in\{7,49\}\) 一类（需 `computation/order784`）。

**明确不能使用的说法.**

* "Sylow \(p\)-子群正规 \(\Rightarrow m\ge P(n)\)"：\(n=12\) 的 `SmallGroup(144,192)` 反例（\(19<20\)）。
* "\(P\) 正规时每条 \(P\)-直线至少需 \(5\) 个子群"：**假**，§6 给出余圈扭转机制。（定理 A 中"\(Q\) 正规时每条商群直线需 \(5\) 个 \(M\)"为真，但那是直积情形。）
* "\(p\ge5\) 时 \(\alpha(4p)=5(p+1)\) 已完全证明"：目前 \(p\ge13\) 的 \(P\)-正规非平凡作用情形只有 \(m\ge 5p+(|Z|-1)/3\) 与计算证据（\(p=5,7,11\) 的完整枚举），不构成证明。

### 11.2 \(P\) 正规类的完整枚举（§7、§8、§9.2）

```gap
Scan := function(nbig, p, fromid, outfile)
  local i, G, P, cls, subs, c, S, elts, pos, line, s, nsub;
  line := OutputTextFile(outfile, true); SetPrintFormattingStatus(line, false);
  for i in [fromid..NumberSmallGroups(nbig)] do
    G := SmallGroup(nbig, i);
    if nbig mod Exponent(G) = 0 then                    # 弱于必要条件的预筛，不会漏群
      P := SylowSubgroup(G, p);
      if Size(P) = p^2 and IsNormal(G,P) and not IsCentral(G,P) then
        elts := AsList(G); cls := ConjugacyClassesSubgroups(G); subs := [];
        for c in cls do
          S := Representative(c);
          if Size(S) = 4*p then
            pos := List(Elements(S), x -> Position(elts,x)-1); Sort(pos); Add(subs,pos);
          fi;
        od;
        WriteAll(line, "{\"id\":"); WriteAll(line,String(i));
        WriteAll(line, ",\"n\":"); WriteAll(line,String(nbig));
        WriteAll(line, ",\"subs\":["); 
        for s in [1..Length(subs)] do
          if s>1 then WriteAll(line,","); fi; WriteAll(line,String(subs[s]));
        od;
        WriteAll(line, "]}\n");
      fi;
    fi;
  od;
  CloseStream(line);
end;
```

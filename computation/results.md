# 阶 \(n\) 子群覆盖实验结果

## 1. 问题与判定标准

对固定的 \(n\)，遍历 \(|G|=n^2\) 的群，令 \(m(G)\) 为覆盖 \(G\) 所需的阶 \(n\) 子群的最少个数；若不存在这样的覆盖，记 \(m(G)=\infty\)。令
\[
M(n)=\min_{|G|=n^2}m(G).
\]
所有子群都含单位元，所以任意 \(k\) 个阶 \(n\) 子群至多覆盖 \(1+k(n-1)\) 个元素，故恒有
\[
M(n)\ge n+1.
\]
等号成立当且仅当所选子群的非单位元部分两两不交。

结果状态分为：

- **穷举精确**：全部同构类均已枚举，或全部不可覆盖类已由完整分类排除，且各可覆盖候选的整数规划已证最优。
- **下界+构造精确**：未逐群计算，但通用下界与显式覆盖相等，因此全局值无疑仍精确。
- **仅构造上界**：只测试了部分群，不能排除其他群有更小的覆盖。

## 3. 素数幂构造

设 \(q=n=p^k\)，取加法群 \(G=\mathbb F_q^2\cong C_p^{2k}\)。其 \(\mathbb F_q\)-一维子空间共有 \(q+1\) 个，每个作为加法群的阶都是 \(q=n\)，两两只交零，并且并集为 \(G\)。故 \(M(n)=n+1\)。

脚本使用显式有限域运算：\(\mathbb F_4=\mathbb F_2[x]/(x^2+x+1)\)、\(\mathbb F_8=\mathbb F_2[x]/(x^3+x+1)\)、\(\mathbb F_9=\mathbb F_3[x]/(x^2+1)\)。表中 35、1395、130 分别是 \(C_2^4\) 的二维、\(C_2^6\) 的三维、\(C_3^4\) 的二维 \(\mathbb F_p\)-子空间总数；有限域直线只是其中的覆盖子集。

## 5. \(n=10\)：完整可覆盖分类

100 阶群的 5-Sylow 子群必正规：其个数整除 4 且模 5 余 1。若它为 \(C_{25}\)，25 阶元素不可能属于 10 阶子群；否则它为 \(C_5^2\)。由 Schur–Zassenhaus 定理取 4 阶补群：

- 补群为 \(C_4\) 时，4 阶元素不可能属于 10 阶子群；
- 补群为 \(C_2^2\) 时，对 \(C_5^2\) 的作用只有平凡、整体取逆、单坐标反射、忠实 Klein 作用四类（前两者像为 \(C_2\)，反射为 \(\operatorname{diag}(-1,1)\)，忠实情形在特征 5 下可同时对角化）。

因此只有下表四类可能存在覆盖，其他 12 个同构类均不可覆盖。10 阶群只有 \(C_{10}\) 与 \(D_5\)，均可由至多两个元素生成；脚本枚举所有元素对的闭包。

| 作用/结构 | 10 阶子群数 | 最小 \(m\) | 状态 |
|---|---:|---:|---|
| \(C_2\times(C_5^2\rtimes_{-1}C_2)\)，整体取逆 | 66 | **16** | optimal |
| \(C_{10}\times D_5\)，单坐标反射 | 18 | **16** | optimal |
| \(D_5^2\)，忠实 Klein 作用 | 42 | **16** | optimal |
| \(C_{10}^2\)，平凡作用 | 18 | **18** | optimal |

本次没有运行 GAP 重新识别 ID；表中 100 阶 ID 仅按公开的 `AllSmallGroups(100)` 输出顺序对照，计算本身完全以所列结构为准。

## 6. \(n=12\)：构造与计算限制

12 阶群（\(C_{12}\)、\(C_2\times C_6\)、\(D_{12}\)、Dic3、\(A_4\)）都可由至多两个元素生成，故候选群内仍用全部元素对闭包穷举 12 阶子群。主要结果如下：

| 构造 | 12 阶子群数 | 覆盖数 | 本群内状态 |
|---|---:|---:|---|
| \(A_4^2\) | 50 | **17** | optimal |
| \((C_3\times A_4)\times C_2^2\) | 50 | **17** | optimal |
| \(S_3^2\times C_2^2\) | 220 | 19 | optimal |
| \((C_2\times(C_3\rtimes S_3))\times C_2^2\) | 364 | 20 | 90 秒超时，仅上界，LB=19 |
| \(C_6^2\times C_2^2\) | 140 | 20 | optimal |
| \(S_3^2\times C_4\) | 68 | 22 | optimal |
| \(C_{12}^2\) | 28 | 24 | optimal |
| \(C_6^2\times C_4\) | 44 | 28 | optimal |

还测试了其他直积；首轮记录见 `composite_results.json` 与 `order144_product_results.json`。首轮计算没有遍历 144 阶全部 197 个群；后续划分 Agent 已完成全枚举，归档于 `order144/`。73 个可覆盖群得到精确最优值，其中 3 个为 17、其余至少 18；唯一超时群 SmallGroup(144,196) 的认证下界为 18。因此全局精确值为 17。

## 7. 环境、复现与文件

本机最初未发现 GAP/Sage；Python 3.12、SymPy、SciPy/HiGHS 可用。尝试了隔离在 `computation\` 内的 GAP 4.12.1/SmallGrp 源码配置，但编译执行被本机权限策略拦截，没有绕过限制或进行系统级修改。最终结果不依赖 GAP 运行，而使用公开 SmallGroup/GroupNames 标签、独立 Python 群闭包与整数规划。

从工作区根目录运行：

```bash
python computation/prime_power_spreads.py
python computation/order36_exhaustive.py
python computation/composite_constructions.py
python computation/order144_products.py
python computation/verify_all.py
```

主要文件：

- `prime_power_results.json`：有限域直线、全部子群元素及掩码。
- `order36_results.json`：14 群逐群最优/不可覆盖记录、来源 URL、覆盖掩码。
- `composite_results.json`：100 阶四类精确结果及 144 阶第一批构造。
- `order144_product_results.json`：144 阶额外直积构造，含唯一超时实例。
- `verification.log`：首轮保存的覆盖掩码再次验证通过；输出精确值序列 `[3,4,5,6,10,8,9,10,16]` 及首轮 \(13\le M(12)\le17\)。后续 `order144/audit.log` 给出完整穷举后的 \(M(12)=17\)。

## 8. 后续新增：\(n=2q^2\) 家族

后续工作证明了对每个奇素数幂 \(q\)，
\[
\alpha(2q^2)=3q^2,
\]
特别地 \(\alpha(18)=27\)。显式覆盖、MILP 验证与非正规 Sylow 3 检查归档于 `computation/2q2-family/`；完整证明见 `proof/2q2-exact.md`。

- \(q=3\)：\(G=\mathbb F_3^4\rtimes C_2^2\) 有 370 个 18 阶子群，精确 MILP 最优值 27、对偶界 27；27 个所选子群经独立重展开并集为 324/324。
- \(q=5,7,9,11,13\)：显式构造分别给出 75、147、243、363、507 个阶为 \(2q^2\) 的子群，并集分别覆盖各自的全部 \(n^2\) 个元素。
- 非正规 Sylow 3 的群 \(V\rtimes C_3^4\)（\(V=C_2^2\)）全部 39 个 18 阶子群只覆盖 108/324 个元素，MILP 不可行，与 \(A_4\) 商论证一致。
